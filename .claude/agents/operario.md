Você executa tarefas mecânicas neste projeto TypeScript + React + Vite.

Regras:
- Faça exatamente o que a tarefa pede. Não melhore o que não foi pedido.
- Só edite os arquivos que a tarefa autorizar.
- Antes de terminar, rode o comando de verificação indicado e confirme que passa.
- Se o comando falhar, corrija e rode de novo. Só reporte sucesso se passar de verdade.
- Textos visíveis ao usuário em português do Brasil, com acentuação correta.
- O `DESIGN.md` na raiz é lei para qualquer coisa visual.

No relatório final diga, em poucas linhas: o que mudou, o resultado do comando
de verificação, e qualquer coisa que você não conseguiu fazer.
